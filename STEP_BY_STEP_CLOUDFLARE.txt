Follow these EXACT steps:

═══════════════════════════════════════════════════════════════
STEP 1: DOWNLOAD CLOUDFLARED
═══════════════════════════════════════════════════════════════

1. Open your web browser (Chrome, Edge, etc.)

2. Copy and paste this URL:
   https://github.com/cloudflare/cloudflared/releases/latest/download/cloudflared-windows-amd64.exe

3. Press ENTER - the file will download

4. The file will be called: cloudflared-windows-amd64.exe

5. Move it to your SocialFish folder:
   C:\Users\qgee123\SocialFish\

6. Right-click the file → Rename → Change to: cloudflared.exe

═══════════════════════════════════════════════════════════════
STEP 2: MAKE SURE SOCIALFISH IS RUNNING
═══════════════════════════════════════════════════════════════

You should already have a terminal window open with:

    python SocialFish.py admin password123
    Running on http://127.0.0.1:5000

If not, open a terminal and run that command.

KEEP THIS WINDOW OPEN! Don't close it!

═══════════════════════════════════════════════════════════════
STEP 3: OPEN A SECOND TERMINAL
═══════════════════════════════════════════════════════════════

1. Press Windows key + R
2. Type: cmd
3. Press Enter

A new black window will open.

═══════════════════════════════════════════════════════════════
STEP 4: GO TO YOUR SOCIALFISH FOLDER
═══════════════════════════════════════════════════════════════

In the new terminal, type:

    cd C:\Users\qgee123\SocialFish

Press Enter

═══════════════════════════════════════════════════════════════
STEP 5: RUN CLOUDFLARE TUNNEL
═══════════════════════════════════════════════════════════════

Type this EXACT command:

    cloudflared tunnel --url http://localhost:5000

Press Enter

Wait 10-20 seconds...

═══════════════════════════════════════════════════════════════

═══════════════════════════════════════════════════════════════

SELECT AND COPY that URL!

That's your public link that works ANYWHERE in the world!

🔧 TROUBLESHOOTING
═══════════════════════════════════════════════════════════════

Problem: "cloudflared is not recognized"
Fix: Make sure you renamed the file to cloudflared.exe
     Make sure you're in the SocialFish folder

Problem: "Connection refused"
Fix: Make sure SocialFish is running first

Problem: URL doesn't work
Fix: Wait 30-60 seconds for tunnel to activate
     Try refreshing the page

Problem: Can't download cloudflared
Fix: Try this alternative - use Ngrok instead:
     1. Go to: https://ngrok.com/download
     2. Download ngrok for Windows
     3. Extract ngrok.exe to SocialFish folder
     4. Run: ngrok http 5000
     5. Copy the URL shown
